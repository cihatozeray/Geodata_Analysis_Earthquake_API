Data visualization project using AFAD Earthquakes API and OpenStreetMap.

By defining location, time and time range, script downloads events data using AFAD API and uploads them into local PostgreSQL database. Then plots those events on OpenStreetMap tiles which is acquired for earlier defined location.  

Map data copyrighted OpenStreetMap contributors and available from https://www.openstreetmap.org

Note: At the moment OpenStreetMap stopped providing tiles for this study. Researching for a solution...
